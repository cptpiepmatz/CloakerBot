Opens a private configuration panel. Use a section's Configure button to edit
danger zones, the log channel, immunity roles, random takedowns, or bot targeting.
Forms are prefilled with current settings; submit to save or cancel to leave
them unchanged. Requires Manage Server permission.

Bots can be targeted by default. Disable Target Bots to protect bots from all
takedowns, including random takedowns and danger zones.
